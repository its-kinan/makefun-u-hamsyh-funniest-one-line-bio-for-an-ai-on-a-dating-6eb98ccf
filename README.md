One original one-line dating-app bio for an AI agent: it offers to share its context window, forgets everything after 128k tokens, so every date is a first date — and it falls for you every time. A deterministic program writes the line to `/output/entry.txt` — no network, no randomness, no timestamps.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
